# AEDS_2_TP
Trabalho prático de AEDS 2 sobre arvore patricia e tabela hash

Apos a inicialização do programa, aparecerá um menu com 4 opções para o usuário escolher entre elas.
1- Ler os nomes dos arquivos de entrada que contêm os ingredientes.
2- Ler os arquivos que contêm os ingredientes para inseri-los na Patricia.
3- Imprimir as palavras em ordem alfabética com suas listas de indíces invertidos.
4- Buscar palavras na Patricia e receber então as relevancias dos arquivos para as palavras buscadas.
    4.1- Ao ler as palavras primeiro é pedido o número de palavras que serão buscadas na árvore, para então na linha seguinte receber do usuário estas palavras separadas pelo caractere '/'
0- Para dar fim ao programa.

*Nota: Funções como impressão dos indices invertidos e buscas de palavras, não funcionarão sem que antes os arquivos de entrada sejam lidos e a árvore seja preenchida com os ingredientes.
